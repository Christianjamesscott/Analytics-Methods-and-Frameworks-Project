# Grader Guide

This repo contains the analytics lane for the NovaBank project.

Start with the [final notebook](../notebooks/99_final_reproducible_notebook.ipynb), then review the [model comparison](../outputs/tables/table_model_comparison.csv), [decision summary](../outputs/tables/table_decision_summary.csv), and [trade-off table](../outputs/tables/table_tradeoffs.csv).

The current recommendation is to use gradient boosting and target the top 20% highest-scoring customers for proactive outreach.

Other useful review files are the [scenario analysis](../outputs/tables/table_scenario_analysis.csv), [assumptions and risks](../outputs/tables/table_assumptions_and_risks.csv), and [proxy framing](../outputs/tables/table_proxy_target_framing.csv).

This repo is the analytics component only; memo and slide deliverables are separate submission components.
